# ⚡ Data Structures & Algorithms (C)

Colección de implementaciones optimizadas de estructuras de datos fundamentales y algoritmia, enfocadas en la eficiencia y gestión de memoria.

### 📂 Contenido
* **Estructuras Dinámicas:** Implementación manual de Listas, Pilas (Stacks), Colas (Queues) y Árboles.
* **Gestión de Memoria:** Uso intensivo de punteros y asignación dinámica (`malloc`/`free`) para optimizar recursos.
* **Algoritmos:** Métodos de ordenación y búsqueda eficientes.

### 🧠 Por qué C?
El uso de C permite un control granular sobre el hardware y la memoria, fundamental para comprender la complejidad temporal y espacial de los algoritmos.
